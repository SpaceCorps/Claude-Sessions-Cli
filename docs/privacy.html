Privacy Policy

Last updated: September 25, 2026

The Claude Sessions CLI (claude-sessions) is designed with an absolute, uncompromising commitment to user privacy and data sovereignty.

1. Zero Telemetry & Zero Analytics

claude-sessions contains no analytics code, tracking beacons, diagnostic phone-home routines, or telemetry collectors. Running the binary will never ping any remote server under any circumstance.

2. Strictly Local Filesystem Operations

The tool reads and copies Claude Desktop metadata files stored locally on your machine. Your prompts, code files, session titles, conversation histories, and directory trees are never transmitted over the internet.

3. Zero Cloud Credentials Required

You are never asked to enter Anthropic account passwords, session cookies, OAuth tokens, or payment details. The CLI reads the local configuration already stored on disk by the official desktop client.

4. Non-Destructive File Copying

All transfers are implemented strictly as copy operations. The application never alters, truncates, or deletes any files in the source account or organization directory.
